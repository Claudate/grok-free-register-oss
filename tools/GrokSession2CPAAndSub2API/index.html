Grok Free Register toolkit

Grok Session → CPA / sub2api

纯前端转换：把注册机 xai-*.json / SSO / accounts / sessions 转成 CPA、sub2api 导入包、batch 建号、或 sso-to-oauth 请求体。本地解析，不上传。

platform: grok base: cli-chat-proxy 有 refresh 不写账号 6h 死期

输入

粘贴 / 拖入 JSON、JSON 数组、jsonl、accounts 行、纯 SSO 行

支持输入
1. authenticated/xai-*.json 或 cpa_ready/xai-*.json
2. sub2api account / accounts 数组 / sub2api-data 包
3. auth-sessions.jsonl（email + cookies.sso）
4. accounts.txt：email:password:sso
5. grok.txt：每行一个 SSO JWT
等待输入 未转换

输出

CPA：type=xai，对齐注册机 cpa_ready / new-api 风格

空

规则：
• free 号 base_url 固定为 https://cli-chat-proxy.grok.com/v1（忽略 authenticated 里的 api.x.ai）
• 有 refresh_token 时：sub2api 账号不写顶层 expires_at/auto_pause，避免 6h 被 pause
• 无 refresh 时：写 access 的 exp + auto_pause，到期停用
• 纯 SSO 输入只能出 sso-to-oauth 请求体；CPA/sub2api 需要 OAuth token
